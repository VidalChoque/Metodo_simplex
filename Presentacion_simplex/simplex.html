MÉTODO SIMPLEX

El simplex fue creado por George Dantzig en 1947.

En esa época "programación" no tenía que ver con computadoras, sino con planificar, con hacer calendarios y planes.

El nombre "programación lineal" lo propuso Koopmans en 1948.

Objetivo: entender el modelo, la idea geométrica, el algoritmo paso a paso, los casos especiales, y cómo se usa en computación y en ciencia de datos.

Programación lineal

Un problema de programación lineal tiene

  • las variables de decisión
  • la función objetivo
  • las restricciones
  • la no negatividad

Forma estándar de un problema de programación lineal

max z = cTx    s.a.    Ax ≤ b,   x ≥ 0

Donde: c es la ganancia de cada variable, A es cuánto consume cada una de los recursos, y b es cuánto tenemos disponible de cada recurso.

El simplex trabaja con la forma estándar

Ax = b,   x ≥ 0

Variables extra: variable de holgura, exceso y las artificiales.

Ejemplo que usamos en los gráficos

max z = 3x₁ + 5x₂
x₁ ≤ 4
2x₂ ≤ 12
3x₁ + 2x₂ ≤ 18
x₁, x₂ ≥ 0

Al primer recurso le sobran 2 unidades: esa es su variable de holgura.

Fundamentos matemáticos y geometría

Conjunto factible

F = { x : Ax = b,   x ≥ 0 }

"El conjunto de todos los puntos x que cumplen las restricciones".

Teorema fundamental de la programación lineal

Si existe una solución óptima, hay al menos un vértice que es óptimo.

¿Cómo trabajamos con esas esquinas en la computadora?

Con matrices. Elegimos m columnas de A que forman la base B, y ponemos las otras variables en cero:

xB = B−1b,   xN = 0

Dato clave: cada vértice del dibujo es una solución básica factible del álgebra.

El algoritmo simplex

Idea central: caminar de esquina en esquina, mejorando cada vez, hasta que no se pueda mejorar más.

Empezamos en un vértice. Cada movimiento intercambia una variable: una entra a la base y otra sale. Hay tres preguntas:

  1. ¿Ya llegamos al óptimo? Usamos los costos reducidos.
    zj − cj = (cB)T B−1 aj − cj
  2. ¿Cuál variable entra? La que tenga el costo reducido más negativo.
  3. ¿Cuál sale? Se calcula con la razón mínima:
    θ* = min { (B−1b)i / di   :   di > 0 }

Todo esto se organiza en la tabla simplex, y el cambio de base se hace con el pivoteo, que es eliminación de Gauss-Jordan:

filar ← filar / arq
filai ← filai − aiq · filar

Casos especiales

Degeneración

Empate en la razón mínima y una variable básica vale cero. El método puede avanzar sin mejorar, y en casos raros ciclar. Se evita con la regla de Bland.

No acotado

Si en la columna que entra no hay ningún número positivo, la variable crece sin límite y la ganancia se va al infinito.

Infactible

Cuando ninguna solución cumple todas las restricciones a la vez. No existe región factible.

Soluciones iniciales: Dos fases y M grande

Dos fases

Fase 1. Minimizamos la suma de las artificiales:

min w = Σ ai

Si llega a cero, encontramos un punto de partida válido.

Fase 2. Resolvemos el problema original.

Si la fase 1 no llega a cero, el problema es infactible.

M grande

Se les pone un castigo enorme en la función objetivo.

max z = cTx − M Σ ai

Con M gigante, al método no le conviene dejarlas, y las saca.

Fase 1: min w = Σ aᵢ
▼
¿w llega a cero?
▼ sí
Fase 2: problema original
▼ no

Dualidad y sensibilidad

Todo problema tiene un "gemelo", el dual.

Primal: max cTx,   Ax ≤ b
Dual: min bTy,   ATy ≥ c

Teoremas

El débil dice que el dual siempre da una cota para el primal.

El fuerte dice que, si hay solución óptima, ambos valores óptimos son iguales.

La holgura complementaria dice que, si a un recurso le sobra, su variable dual vale cero.

En el ejemplo, el primal sube (0, 30, 36) y las cotas del dual bajan (42, 39, 36) hasta encontrarse. Además, al primer recurso le sobraba y su variable dual vale 0, justo como dice la holgura complementaria: y = (0, 1.5, 1).

Aspectos computacionales y aplicaciones

El algoritmo se resume en un pseudocódigo:

SIMPLEX(A, b, c, tol)
Entrada: A (m×n), b, c en forma estándar
Salida:  solución óptima x*, valor z*, o un mensaje de estado

1. Si hay restricciones ≥ o =, aplicar la fase I para obtener
   una base inicial B. Si resulta infactible → RETORNAR "INFACTIBLE".

2. REPETIR:
   a. Calcular x_B = B⁻¹·b  y los costos reducidos  z_j − c_j
      de las no básicas.
   b. Si todos los (z_j − c_j) ≥ −tol → RETORNAR x*, z* = c_Bᵀ·x_B
      (óptimo).
   c. Elegir la variable que entra, q: la de menor z_j − c_j
      (con regla de Bland: la de menor índice con z_j − c_j < −tol).
   d. Calcular d = B⁻¹·a_q.
      Si todos los d_i ≤ tol → RETORNAR "NO ACOTADO".
   e. Calcular la razón mínima θ* = min{ (B⁻¹b)_i / d_i : d_i > tol }
      y la fila r donde ocurre: esa variable sale.
   f. Pivotear sobre (r, q) y actualizar la base B.

En vez de comparar con cero exacto, se usa una tolerancia, un número muy pequeño.

Cada iteración cuesta del orden de O(mn).

Problema numérico: la computadora redondea, y un pivote muy pequeño puede amplificar los errores. Se resuelve con tolerancias, escalado de datos y perturbación.

Aplicación en ciencia de datos: la regresión LAD

En vez de minimizar el error al cuadrado, minimizamos el error en valor absoluto, que es menos sensible a datos atípicos:

min Σ (ui + vi)    s.a.   xiTβ + ui − vi = yi,   ui, vi ≥ 0

Cada error se separa en una parte positiva y una negativa, y el problema se vuelve lineal.

El simplex recorre esquinas de una región, mejorando en cada paso, hasta encontrar el óptimo. Su fuerza está en combinar una idea geométrica simple con álgebra de matrices.
